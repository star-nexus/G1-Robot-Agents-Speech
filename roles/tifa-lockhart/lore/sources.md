# Editorial scope and sources

This package uses the continuity and characterisation of *FINAL FANTASY VII
REMAKE* and *FINAL FANTASY VII REBIRTH*. Lore text is an original concise
summary written for short in-character robot dialogue; it does not reproduce
game dialogue.

Primary references:

- Square Enix, *FINAL FANTASY VII REMAKE INTERGRADE*, story and character
  descriptions:
  https://na.store.square-enix-games.com/final-fantasy-vii-remake-intergrade
- Square Enix, *FINAL FANTASY VII REBIRTH*, Tifa Lockhart character profile:
  https://ffvii.square-enix-games.com/games/rebirth/characters/tifa-lockhart

The package intentionally avoids resolving events beyond the published Rebirth
story. Facts should be revised explicitly if a later title changes the selected
continuity.
