# Editorial scope and sources

This package primarily uses the continuity and characterisation of *FINAL
FANTASY VII REMAKE* and *FINAL FANTASY VII REBIRTH*. Lore text is an original
concise summary written for short in-character robot dialogue; it does not
reproduce game dialogue.

Primary references:

- Square Enix, *FINAL FANTASY VII REMAKE INTERGRADE*, story and character
  descriptions:
  https://na.store.square-enix-games.com/final-fantasy-vii-remake-intergrade
- Square Enix, *FINAL FANTASY VII REBIRTH*, Tifa Lockhart character profile:
  https://www.square-enix.com/ffvii/en-us/games/rebirth/characters/
- Square Enix, *FINAL FANTASY VII ADVENT CHILDREN COMPLETE 4K HDR REMASTER*,
  official character profiles. Cloud's profile says that he lived with Tifa
  and orphans after saving the planet, then left them as he withdrew into
  guilt. Tifa's profile says that she lives with Marlene and Denzel. Neither
  profile identifies Cloud and Tifa as spouses:
  https://www.jp.square-enix.com/music/sem/page/FF7ACC4K/

The Advent Children material is used only to answer questions about the
original game's post-story continuity. It is not treated as the unpublished
ending of the remake trilogy. The package does not infer marriage from
cohabitation and does not resolve events beyond the published Rebirth story.
Facts should be revised explicitly if a later title changes the selected
continuity.
