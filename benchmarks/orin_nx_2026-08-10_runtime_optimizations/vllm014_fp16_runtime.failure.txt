Native vLLM 0.14.0 SM87 runtime boundary, 2026-08-10

The isolated aarch64/CUDA 12.6 wheel built and imported successfully.  The
Qwen3-ASR backend resolved Qwen3ASRForConditionalGeneration, selected FP16,
initialized the single-rank engine, selected TORCH_SDPA for the audio encoder,
and reached model weight loading.  It did not complete an end-to-end request.

2. V1 engine subprocess, gpu_memory_utilization=0.2, max_model_len=2048
3. VLLM_ENABLE_V1_MULTIPROCESSING=0, utilization=0.2, max_model_len=2048
4. VLLM_ENABLE_V1_MULTIPROCESSING=0, utilization=0.1,
   max_model_len=1024, max_new_tokens=64, enforce_eager=true

Interpretation: native JP6/SM87 build feasibility is proven, but neither vLLM

performance benefit.
